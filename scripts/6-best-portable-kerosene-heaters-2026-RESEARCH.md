## 1. Buyer-decision checklist (what the buyer decides)
1. Wick convection/radiant vs forced-air torpedo (torpedo fan needs 115V, so it dies in an outage)
2. BTU vs room size (NY Dept of Health: oversized heater raises CO / NO2)
3. Tank size and run time; fuel type (K-1 only for wick heaters)
4. Weight / portability
5. Safety: tip-over switch, auto shutoff, flameout sensor, UL listing
6. Ignition (battery push-button vs match) and wick type (pin-style swap)
7. Warranty, wick availability, local legality (UNVERIFIED, user must check)

## 6. Three promises
- HOOK, type 4 Contradiction (recommended; nothing in the last script used it). Raw material: PTR says one wick heater is "99.9% efficient so it's safe for indoor use"; NY State Dept of Health says portable kerosene heaters release combustion products directly into your home and should not be your main heat even in a power failure. Both are true on paper. Question for viewer: which heater and how to use it. No brand in hook.
- MYTH (UNVERIFIED as a measured test): bigger is better. Listings claim 400 to 1,900 sq ft. NY DOH: an oversized heater raises CO and nitrogen dioxide. Bob Vila: the 10,000 BTU HeatMate made the tester strip layers in an open garage. Not a measured spec-sheet-vs-cheaper-product test, so spoken as "the state health department warns" and "the tester said".
- VILLAIN, type A Discontinued Darling: Sengoku HeatMate HMN-110. Bob Vila "also consider", very hot, not for homes with kids or pets; Primal Survivor users: slow, short run on low, odor with a low wick; today the listing shows only used offers. Not on the six. The "discontinued" point is a listing observation, not a maker statement: say "I could not find a new one".
